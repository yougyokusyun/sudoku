## 5. 规格文档摘要（`docs/idiom-image-spec.md`）

| 项 | 推荐值 |
| --- | --- |
| 方版 1:1 | 640×640（1x）/ 1280×1280（2x），单张 ≤80 KB / ≤200 KB |
| 横版 4:3 | 512×384（1x）/ 1024×768（2x），单张 ≤60 KB / ≤150 KB |
| 格式 | WebP 优先（q78，`-m 6`）；JPEG q82 兜底；PNG 仅线稿 |
| 画风 | 统一儿童水彩绘本风；背景 `#FBF3E4`；主体占 55%~70%；四周留白 ≥12% |
| iPad 可辨 | 显示短边 ≥240 CSS px；主体短边 ≥120 CSS px（2x ≥240 物理像素） |
| 命名 | `games/img/idiom/<pinyin>.webp`，同成语变体加 `-2` |
| 授权 | A 档：CC0 / PD / CC-BY / CC-BY-SA / 自有；B 档不得进公开仓库 |
| 缓存 | 不进 `PRECACHE`，仅运行时缓存 |
| 审核 | 盲测 5 人，≥4 人在 5 秒内说对成语才通过 |

## 6. 遗留与后续建议

已确认的限制：

1. 成语配图为统一水彩绘本风，**不是真实照片**；与英文看图选句的实景照片风格不同，跨页不能直接复用。
2. 成语「真实出处」仅 **74/507** 可核查，其余为「无明显典故 / 后起说法」的如实说明，属内容深度限制。
3. 谜语与成语数据为整份 JSON 首次加载：`riddles.json` 70,684 B、`idioms-all.json` 142,528 B；弱网首屏仍有一次性成本（未做分片）。
4. iPad 端 Service Worker 更新通常需**完全关闭页面再打开**才切换新缓存；本轮**未在真机实测**。
5. 首页卡片数与需求文本口径不一致（实测 28/11/28），差异原因未核验。
6. 四页图标放大只留「约 1.5 倍」记录，精确像素未留档；形状拖拽、成语页「0 偏移」未在本轮重跑回归。
7. 推送使用的 GitHub Token 建议在确认本轮工作结束后 **revoke**（安全建议，非功能问题）。

可选下一步（按优先级）：

1. 为谜语/成语 JSON 做按类别分片或首屏截断加载，降低首装体积。
2. 补 v40 图标改造的精确像素基线，纳入回归脚本。
3. 成语配图按规格补 2x（1280×1280）版本，或按页面需要引入 4:3 横版图。
4. 真机（iPad Safari）跑一次 SW 更新与横竖屏回归。
